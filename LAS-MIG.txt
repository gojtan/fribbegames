FRIBBEGAMES – HTML/CSS OCH GITHUB PAGES

LOKALT
Packa upp hela ZIP-filen. Dubbelklicka på index.html.
Behåll assets-mappen bredvid HTML-, CSS- och JavaScript-filerna.
Du behöver ingen server, installation eller byggprocess.

GITHUB PAGES
1. Skapa ett GitHub-repository.
2. Ladda upp innehållet i den uppackade mappen till repositoryts rot.
   index.html ska ligga direkt i roten, inte i en extra undermapp.
3. Öppna Settings > Pages.
4. Under Build and deployment, välj Deploy from a branch.
5. Välj main och /(root), och spara.
6. När publiceringen är klar, öppna adressen som GitHub visar.

Relativa länkar gör att sidan även fungerar under /repository-namn/.
Filen .nojekyll gör att innehållet serveras som statiska filer.
Vid egen domän: lägg till domänen i GitHub Pages och konfigurera DNS.

FILER
index.html – startsidan
style.css – design
app.js – mobilmeny och supportformulär
support.html – support
privacy.html – privacy policy
 data-deletion.html – radering av data
404.html – felsida
assets/ – bilder och favicon

Supportformuläret öppnar besökarens mejlprogram. Det skickar inget automatiskt.
Alla HTML-sidor ligger i huvudmappen. Endast bilder ligger i assets/.
HTML, CSS och JavaScript är formaterade med indrag och radbrytningar.

404.html använder relativa länkar som fungerar från webbplatsens rot;
GitHub Pages felsidor på godtyckliga djupa adresser kan kräva anpassning.

INNAN LANSERING
Lägg till riktiga Google Play-länkar och stäm av integritetsutkasten mot
spelversionerna och tjänsterna som faktiskt används.
